# 🛣️ 도로로(Dororo) - 도로 균열 보수 동아리 웹사이트

안전한 도로 환경을 위해 활동하는 교육 동아리 **도로로**의 공식 랜딩 페이지 프로젝트입니다.

## 📋 프로젝트 개요
이 프로젝트는 동아리 소개, 학습 목표, 퀴즈 참여 및 성과 공유를 위한 싱글 페이지 웹사이트입니다. 특히 '우리의 성과' 버튼을 통해 활동 사진을 확인할 수 있는 모달 팝업 기능이 구현되어 있습니다.

## 📂 파일 구조
```text
project-root/
│
├── index.html         # 메인 구조 및 모달 스타일
├── style.css          # 전체 웹 디자인 (폰트, 레이아웃)
├── script.js          # 모달 제어 및 인터랙션
└── image/             # 이미지 리소스 폴더
    └── 도로균열.png    # 성과 확인용 이미지
